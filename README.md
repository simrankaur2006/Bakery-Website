# 🧁 Bakery Website

A responsive and user-friendly **Bakery Website** built to showcase bakery products through a clean and attractive web interface. The project focuses on creating an engaging frontend experience using HTML, CSS, and JavaScript.

## 🚀 Features

- 🧁 Attractive bakery-themed user interface
- 🍰 Product showcase section
- 📱 Responsive design
- 🎨 Clean and modern layout
- 🛒 Interactive elements using JavaScript
- 🖼️ Product and bakery visuals
- ⚡ Lightweight and fast frontend

## 🛠️ Tech Stack

- **HTML5** – Structure and content
- **CSS3** – Styling, layout, and responsiveness
- **JavaScript** – Interactivity and dynamic functionality
